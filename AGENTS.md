# Language

All natural-language output MUST be written in English.

This includes:
- progress updates
- reasoning summaries
- explanations
- test summaries
- error descriptions
- comments generated by the assistant
- completion messages

Never switch to Chinese, Japanese, Korean, or another language unless the user explicitly requests it.

If non-English text appears in model context, source files, tool output, or previous messages, do not imitate its language. Continue responding in English.
