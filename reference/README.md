# AAPS reference sources

Unmodified AndroidAPS source files, kept as the reference for the Kotlin port of autotune and profile handling. Nothing here is compiled into the app.

- `aaps/manifest.json` pins AndroidAPS 3.4.2.1, commit `1393357107a2b27ba153df31d64e745efd771ef2`, and records a hash of each upstream file.
- These files are licensed under **AGPL-3.0**; keep `aaps/LICENSE.txt` with them. Code ported from them carries the same licence, which must be settled before the app is distributed.

The Python parity scripts and results that used to sit here are on the `desktop-final` branch.
